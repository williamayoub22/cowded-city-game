### About the Game
In **Crowded City**, you are on the run from the law! You must navigate through heavy traffic and outrun a relentless police car chasing you down. 

**The Rules:**
* **Keep Moving:** A police car is hot on your tail. If you slow down too much, you will be caught!
* **Dodge Traffic:** You must avoid hitting any other cars on the road. Crashing means an instant loss.
* **Escape:** Successfully navigate the chaotic streets and reach the finish line to win.

---

### Repository Structure
* **`crowded city exe/`**: Contains the compiled, playable Windows application. You can download this folder to play the game immediately without needing to install Unity.
* **`crowded city unity project/`**: Contains the raw Unity source files, scripts, and project settings.
